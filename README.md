# 🐾 MundoPet

## 📌 Sobre o projeto

O **MundoPet** é um sistema web desenvolvido para facilitar o cadastro e o gerenciamento de informações sobre animais de estimação.

A aplicação permite cadastrar pets, consultar os animais cadastrados, editar suas informações e excluir registros quando necessário.

O projeto foi desenvolvido utilizando Python e Flask no back-end, SQLite para armazenamento dos dados e HTML, CSS e Bootstrap para a interface.

---

## 🎯 Objetivo

O objetivo do MundoPet é criar uma aplicação web simples e organizada para gerenciamento de informações de pets.

Com o sistema, é possível:

- 🐶 Cadastrar um pet
- 🐾 Consultar pets cadastrados
- ✏️ Editar informações
- 🗑️ Excluir registros
- 📋 Organizar os dados dos animais

---

## 💻 Tecnologias utilizadas

- **Python 3**
- **Flask**
- **Flask-SQLAlchemy**
- **SQLite**
- **HTML5**
- **CSS3**
- **Bootstrap 5**
